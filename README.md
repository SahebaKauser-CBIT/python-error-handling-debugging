
# Python Error Handling and Debugging

## About the Project

This project demonstrates exception handling and
debugging techniques using Python.

## Features

- Handles invalid user input
- Handles division by zero
- Demonstrates try-except-else-finally
- Demonstrates syntax error debugging
- Shows how to identify and fix errors

## Project Structure

```text
python-error-handling-debugging/
├── src/
│   ├── exception_handling.py
│   └── debugging_example.py
├── docs/
│   └── error_handling_notes.md
├── screenshots/
├── README.md
└── .gitignore
```

## How to Run

Run the exception handling program:

```bash
python src/exception_handling.py
```

Run the debugging example:

```bash
python src/debugging_example.py
```

## Concepts Used

- try-except
- ValueError
- ZeroDivisionError
- else and finally
- Syntax errors
- Logical errors
- Debugging
